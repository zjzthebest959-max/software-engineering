# 校园活动管理系统 V1.0（静态版）

## 使用方式

双击同目录的 `index.html`，或双击 `启动系统.bat`，即可在浏览器中打开系统；不需要安装 Python、数据库或启动服务。

演示账号：

- 教师：`teacher` / `123456`
- 学生：`student` / `123456`

## 最小原型功能

- 学生、教师注册和登录，按角色显示功能区域
- 已发布活动浏览、学生报名与我的报名记录
- 教师发布、取消本人活动，并查看报名名单
- 报名时校验活动状态、截止时间、重复报名和人数上限

不包含支付、通知、评论、收藏、签到、审批、跨设备同步等非核心功能。

## 数据说明

账号、活动和报名记录保存在当前浏览器的 `localStorage` 中，不会上传网络。使用“恢复演示数据”会清除本浏览器中的当前记录并恢复初始演示账号和活动；清除浏览器站点数据也会丢失记录。

## 开发验证

如果电脑上有 Node.js，可运行：

```powershell
node tests/static_app.test.js
node --check app.js
```

原有 `app.py`、`requirements.txt` 和 Python 测试仅为旧 Flask 原型的保留文件，不是静态版的运行依赖。
